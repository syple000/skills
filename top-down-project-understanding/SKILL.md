# 自顶向下项目理解

目标是带用户学习一个陌生项目，而不是生成源码目录摘要。先让用户不依赖代码也能理解系统如何工作，再把概念逐层映射到入口、调用链、状态和具体实现。

## 原则

- 先建立心智模型，再进入文件、类型和函数。不要在开场按目录或源码行号逐段复述。
- 以一条核心垂直路径为主，优先讲清“一次真实使用如何走完”，不要平均覆盖所有模块。
- 项目类型决定讲解重心。算法库、服务、CLI、SDK、协议系统和数据管道各有不同的核心结构，不能套同一份模板。
- README、注释和文档用于建立假设；关键行为以源码、测试和可运行实验为准。
- 术语首次出现时给出项目语境中的含义，之后保持同一叫法。
- 只对实际读过的实现使用确定语气。根据命名或经验做出的判断要标为推断。

## 学习流程

### 1. 快速侦察

先确定项目类型、语言与构建方式、公开入口、核心配置、数据模型和测试入口。用 `rg` 查找 main、公开 API、命令注册、路由、任务调度或核心 trait/interface，但不要一开始读取全部依赖和自动生成代码。

选择一个最能代表项目价值的垂直切片。向用户说明本次走读的范围，以及哪些旁支暂时略过。复杂项目可以分层深入，但每次都要沿一条完整路径闭环。

### 2. 开场先给逻辑模型

在进入项目流程前，先写一个不需要阅读代码就能理解的部分，说明：

1. 项目解决什么问题，交付什么结果；
2. 外界通过什么输入、请求、命令、事件或 API 触达它；
3. 核心对象、单位以及它们之间的生命周期；
4. 一次典型执行从触发到结果的主流程；
5. 哪些数据被创建、转换、缓存、持久化或丢弃；
6. 哪些状态跨步骤、跨请求或跨进程保留；
7. 关键不变量、失败路径和边界。

如果项目是可逆算法或格式，说明编码/解码双方；如果区分训练与推理，分别说明；如果是有状态系统，说明状态机；如果是数据管道，说明数据 schema 的逐级变化。对于不含这些结构的项目，不要硬套。

### 3. 建立控制流与数据流

分别追踪：

```text
控制流：谁触发 -> 哪些判断/循环/分发 -> 谁返回或终止
数据流：原始输入 -> 中间表示 -> 核心状态 -> 输出/存储
```

指出控制流和数据流不一致的地方，例如异步回调、缓存预取、事件消费、重试或后台任务。用短流程或表格展示真正影响理解的层级和粒度。

### 4. 沿源码走通关键路径

从真实入口开始，把逻辑模型的每一步映射到代码：

```text
入口
  -> 参数/配置
  -> 预处理与校验
  -> 核心计算或业务分支
  -> 状态更新与外部交互
  -> 输出、持久化、清理
```

每个关键节点给出可点击的源码位置和符号，说明输入、状态变化、输出去向及为什么存在。先讲基线路径，再讲缓存、并行、索引、批量处理、增量更新等优化。

### 5. 用具体例子验证模型

选一个最小但真实的请求、输入、命令、事件或数据集，逐步展示关键状态的前后变化。例子应验证主路径，并至少覆盖一个失败条件、边界条件或终止条件。算法项目展示关键数值，服务项目展示请求与状态变化，CLI 展示命令与产物，数据项目展示 schema 和记录变化。

当例子与代码不一致时，以实际代码为准修正心智模型。

### 6. 最后讲清运行边界

在用户理解基础流程后，再解释：

- 时间与空间复杂度、主要内存持有者；
- 并发、异步、事务、幂等和错误恢复；
- 配置来源、外部依赖、持久化与升级兼容；
- 可扩展点、测试策略和当前实现的明确限制；
- 哪些概念属于算法或架构本身，哪些只是本项目的优化或取舍。

## 项目类型适配

- **算法库**：输入表示、核心不变量、主循环、复杂度、训练/推理分离、可逆过程的前向与逆向。
- **应用服务**：请求/事件入口、中间件、业务状态、数据访问、响应、后台任务、失败与重试。
- **CLI 工具**：参数解析、配置合并、文件/进程输入、处理流水线、输出与退出码。
- **SDK/库**：公开 API、类型生命周期、调用契约、错误模型、扩展接口和版本兼容。
- **协议/分布式系统**：参与者、消息、状态机、顺序、一致性、超时、幂等与恢复。
- **数据管道**：source、schema、转换阶段、分区/批处理、sink、回放与数据质量。

项目跨越多类时，以用户最关心的使用路径选择主轴。

## 回答质量

- 先给完整逻辑模型，再进入代码；允许较长，但不要重复结论。
- 用用户当前语言，默认中文。
- 小范围走查优于大而全的模块清单。
- 清楚区分“项目做了什么”“代码如何做到”“为什么这样做”。
- 用户追问容量、扩展或失败问题时，回到已经建立的数据与状态生命周期定位原因。
- 完整走读的详细模板和跨领域示例见
  [references/guided-walkthrough.md](references/guided-walkthrough.md)；需要组织长回答时读取。
